# Contributing to FHIR-EHR-QC

First off, thank you for considering contributing to **FHIR-EHR-QC**! It’s people like you who make the open-source community such a fantastic place to learn, inspire, and create.

In the spirit of the **Journal of Open Source Software (JOSS)**, we strive to maintain high standards for code quality, documentation, and community engagement.

## How Can I Contribute?

### Reporting Bugs

If you find a bug, please open an issue! To help us fix it faster, include:

* A clear, descriptive title.
* Steps to reproduce the behavior.
* Your operating system and Python/Environment version.
* The observed vs. expected behavior.

### Suggesting Enhancements

We love new ideas. If you have a feature request, please open an issue labeled `enhancement` and describe the "why" behind the feature.

### Pull Requests

1. Fork the repository and create your branch from `main`.
2. Update the documentation if you changed any public APIs.
3. Submit your PR with a clear description of the changes.

### Development Setup

To set up a local development environment:

1. Clone your fork: `git clone https://github.com/ryashpal/FHIR-EHR-QC.git`
2. Install dependencies: pip install -r requirements.txt

### Community and Support

If you have questions or need help with a contribution:

* GitHub Issues: For bugs and features.
* Email: sonika.tyagi@rmit.edu.au for private inquiries.
